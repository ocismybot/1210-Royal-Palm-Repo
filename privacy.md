# Privacy Policy

**Last updated: October 1, 2026**

## 1210 Royal Palm Rclone

1210 Royal Palm Rclone is a private integration used to support project-file coordination for the 1210 Royal Palm project. It uses Google Drive APIs through rclone to access Google Drive data authorized by the Google account owner.

## Google Drive Data Access

Depending on the configuration selected by the account owner, the integration may:

- Read and download authorized Google Drive files and file metadata.
- Create or upload project-output files to designated Google Drive locations.
- Access only the permissions granted by the account owner through Google OAuth.

## How Google Drive Data Is Used

Google Drive data is used only to provide the project's authorized file-management and processing workflow. This may include synchronizing project files to private project systems, processing those files with authorized project tools, and returning authorized project outputs to Google Drive.

Google Drive data is not sold, used for advertising, or used to build advertising profiles.

Google Workspace API data is not used to develop, improve, or train generalized or non-personalized artificial intelligence or machine-learning models.

## Data Storage and Security

Files required for the project workflow may be stored on private project systems controlled by the account owner. OAuth credentials and access tokens are kept on private systems and are not intentionally published in public repositories.

Reasonable administrative and technical safeguards are used to restrict access to authorized project systems and users.

## Data Sharing

Google Drive data is not sold or provided to unrelated third parties. Data may be processed by service providers or project automation systems only when necessary to perform functionality specifically authorized by the account owner.

## User Control

The Google account owner controls authorization for this integration and may revoke Google account access at any time through Google's account security settings.

Locally stored project files may also be removed from project systems when they are no longer required.

## Google API Limited Use

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
